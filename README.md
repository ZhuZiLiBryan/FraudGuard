# FraudGuard
End-to-end fraud detection platform using the IEEE-CIS Fraud Detection dataset, containing a reproducible ML training pipeline, model registry, low-latency prediction API, containerized infrastructure, streaming transaction simulator, monitoring dashboards, automated tests, deployment pipeline, and technical architecture documentation.


Version of the dataset is saved via a SHA256 Hash saved in `configs/data/versions`.  The train/val/test split thresholds for dataset version are also stored here for reproducibility
